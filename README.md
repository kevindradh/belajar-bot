**CodeDojo** adalah bot Discord interaktif yang menghadirkan pengalaman latihan *coding* bergaya Codewars langsung di dalam server Discord Anda. Asah logika pemrograman Anda, kerjakan soal harian bersama teman server, kumpulkan *Experience Points* (XP), dan jadilah **Grandmaster**!

## ✨ Fitur Utama
- 🧩 **Koleksi Soal Terstruktur:** Ratusan tantangan dari tingkat *Easy*, *Medium*, hingga *Hard*.
- ⚡ **Auto-Judge System:** Kode dievaluasi secara instan dan aman menggunakan Judge0.
- 📆 **Daily Challenge:** Soal harian yang di-generate setiap jam 08:00 WIB untuk dikerjakan bersama satu server.
- 🏆 **Gamifikasi:** Sistem Leveling, XP, *Streak*, dan perolehan *Badges* eksklusif.
- 📊 **Leaderboard:** Papan peringkat lokal per-server untuk memacu semangat kompetisi.

## 🛠️ Daftar Command
Bot ini menggunakan sistem *Slash Commands* Discord:

| Command | Deskripsi |
| --- | --- |
| `/challenge` | Dapatkan soal latihan acak sesuai progres Anda. |
| `/submit` | Kirim kode solusi Anda (mendukung Python & JavaScript). |
| `/daily` | Lihat atau kerjakan soal harian khusus server ini. |
| `/profile` | Cek statistik, level, XP, dan badge yang Anda kumpulkan. |
| `/leaderboard` | Lihat Top 10 programmer terbaik di server ini. |
| `/streak` | Cek rentetan *login* Anda dan gunakan *streak freeze*. |
| `/hint` | Beli petunjuk soal seharga 10 XP. |
| `/categories` | Lihat daftar kategori algoritma yang tersedia. |

> **Khusus Admin Server:**
> - `/setup` : Daftarkan server ke dalam database CodeDojo.
> - `/set-channel` : Tentukan channel khusus untuk notifikasi *Daily Challenge*.
